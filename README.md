# 宝淘淘汇总数据 · 经营分析看板

> 电商经营日报 / 月报可视化看板（净利润为核心指标）

基于 Excel 原始报表加工的静态分析看板，支持日报 + 月报双视图切换，内嵌全量数据（2022-06 ~ 2024-05）。

## 预览

访问 [https://jinlaba.github.io/Baotao-Profit-Demo/](https://jinlaba.github.io/Baotao-Profit-Demo/) 查看。

## 功能

- **日报（运营执行视角）**：按净利润排序看运营 / 店铺 / 商品一线执行表现；近 30 天趋势、流量漏斗（访客→买家→成交→利润）、盈亏概览、退款率
- **月报（经营管理视角）**：月度利润结构、利润变动归因瀑布、推广费 & 补单占比专项分析、主管净利润排名
- **净利润为中心**：边际贡献（毛利−佣金−推广费）→ 净利润（边际贡献−分摊费用）全链路拆解
- 任意日期 / 月份切换（日报 702 天、月报 24 个月）

## 数据口径

```
净收入   = 订单收入 − 补单收入 − 退款金额 − 其他减免
毛利     = 发货收入 − 商品成本 − 快递费          （发货收入为真实收入，与净收入存在确认时间差）
边际贡献 = 毛利 − 平台佣金 − 推广费
净利润   = 边际贡献 − 总分摊费用                  （补单成本不参与利润链路）
补单占比 = 补单收入 ÷ 订单收入
```

## 复现方式

数据更新后重新生成看板（需 Python + pandas / openpyxl）：

```bash
cd scripts
python extract_bt.py   # 读取原始 Excel → 生成 ../data/_data_bt.json
python gen_bt.py       # 读取 JSON + bt_tpl.html 模板 → 生成 index.html
```

原始 Excel 不包含在本仓库中（数据为内部经营参考，姓名与商品 ID 均已打码处理）。
